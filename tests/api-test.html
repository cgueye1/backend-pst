⚠️ Problème de connexion ?

Si vous voyez "Failed to fetch", suivez ces étapes :

  1. Ne pas ouvrir le fichier directement (file://) - Utilisez un serveur HTTP local
  2. Option 1 : Utilisez l'extension "Live Server" dans VS Code
  3. Option 2 : Lancez : python -m http.server 8000 puis ouvrez http://localhost:8000/tests/api-test.html
  4. Option 3 : Utilisez Node.js : npx http-server -p 8000
  5. Vérifiez que le serveur API est bien démarré à http://86.106.181.31:3000
💡 Astuce : Si vous êtes dans VS Code, installez l'extension "Live Server" puis faites clic droit sur ce fichier → "Open with Live Server"
