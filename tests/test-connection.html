🔧 Solutions possibles

Si toutes les requêtes échouent avec "Failed to fetch":

1. Vérifiez que le serveur est démarré:
- Connectez-vous au serveur et vérifiez que Next.js tourne sur le port 3000
- Testez: curl http://86.106.181.31:3000/api/test

2. Problème de firewall:
- Le port 3000 peut être bloqué par un firewall
- Vérifiez les règles de firewall sur le serveur

3. Problème de réseau:
- Vous n'êtes peut-être pas sur le même réseau que le serveur
- Essayez d'accéder directement: http://86.106.181.31:3000/api/test

4. Serveur non accessible depuis Internet:
- Le serveur peut être configuré pour n'accepter que les connexions locales
- Vérifiez la configuration Next.js (hostname, etc.)

5. Utilisez un proxy ou VPN:
- Si le serveur est sur un réseau privé, utilisez un tunnel SSH ou VPN
